## About
This resource is a modernized edit of the original [nad_rockstar](https://github.com/Nads-Development/nad_rockstar) resource by Nads-Development.

The menu has been redesigned using ox_lib's context menus and notification system, providing a cleaner and more modern user experience while maintaining the original functionality.

Perfect for servers already using ox_lib or those looking to standardize their UI around the ox_lib ecosystem.

## Features
- Modern ox_lib context menu interface
- ox_lib notification support
- Lightweight and easy to configure
- Clean and user-friendly design
- Simple integration into existing servers

## Dependencies
- [ox_lib](https://github.com/overextended/ox_lib) - by overextended

## Installation
1. Download the resource.
2. Ensure ox_lib is installed and started before this resource.
3. Add the resource to your server.
4. Configure `config.lua` to your liking.
5. Restart your server.
